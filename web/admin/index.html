출석 현황 조회

하이픈(-) 없이 숫자만 입력해주세요

출석률 순위

정렬 기준: 출석 횟수 우선, 동률이면 평균 출석 오프셋이 빠른 순서입니다.

시즌 일정 등록/수정

캘린더에서 날짜를 고르고 시간을 입력하면 회차 키를 자동으로 생성합니다. 종료 시각은 시작 시각과 변수값을 기준으로 자동 제안됩니다.

회차 키와 마감 계산 정보가 여기에 표시됩니다.

현재 시즌 일정 목록

variable 시트 변수 편집

key | value | type | description | editable | updated_at | applies_to | applies_when | used_in 단일 테이블(A:I) 기준입니다. 운영자는 value만 수정하며, 나머지 메타 정보는 템플릿 기준으로 유지됩니다.

변수를 선택하면 설명이 표시됩니다.

값을 바꾸기 전에 “이 값이 어디에 적용되는지”를 먼저 확인하세요.

수료 판정 대시보드

필참/최소 출석/결석환산 조건을 기반으로 현재 수료 가능 여부를 계산합니다.

회원별 수료 판정표

기본 정렬: 출석 높은 순(동률 시 출석률/결석환산). 열 제목을 클릭하면 오름/내림 정렬이 전환됩니다. 한 번에 20명씩 로드됩니다.

유고 처리 매트릭스

색상 기준: 출석(연초록), 지각(연주황), 결석(연빨강), 유고(연파랑).
셀을 클릭하면 유고 설정/해제와 코멘트(Note) 저장이 가능합니다.
