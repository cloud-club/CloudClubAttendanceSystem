Cloud Club 출석 시스템 · 시행일 2026-07-14

이 문서는 출석 시스템의 실제 데이터 흐름을 설명합니다. 운영 정책이나 관련 법령이 바뀌면 Cloud Club 운영진이 내용을 검토하고 갱신합니다.

처리 목적과 항목

  • 전화번호와 출석 시각: 회원 확인, 출석 기록과 통계 제공을 위해 Google Sheets에 저장합니다.
  • 현재 위치와 정확도: 장소 제한 회차에서 지정 장소 반경 500m 여부를 한 번 판정하기 위해 처리합니다.
  • Google Place ID: 회차별 지정 장소를 식별하기 위해 해당 회차의 Sheets 헤더에 저장합니다.

현재 위치의 전송과 보관

위치 필수 회차에서 사용자가 출석 버튼을 누를 때 브라우저가 위치 권한을 요청합니다. 현재 좌표와 정확도는 HTTPS를 통해 기존 Google Apps Script로 전송되고 거리 판정에만 사용됩니다. 참가자 좌표는 Google Sheets, 셀 Note, 브라우저 localStorage에 저장하지 않습니다.

지정 장소 좌표는 Apps Script가 Google Places API에서 조회하며, 반복 조회를 줄이기 위해 최대 6시간 동안 Apps Script Cache에 임시 보관될 수 있습니다. 이 캐시는 일정 유효기간과 무관합니다.

본인 출석 사유의 공개 범위

학생이 요청한 전화번호의 본인 출석 현황을 조회할 때만, Note 선두의 공개 영역에서 해당 회차의 현재 출석·지각·결석 상태와 정확히 일치하는 공개 prefix로 시작하는 첫 번째 비어 있지 않은 사유를 최대 300자까지 보여 줄 수 있습니다. 유고는 사유 없이 상태만 표시합니다. 빈 줄은 건너뛰지만, 첫 번째 비어 있지 않은 줄이 상태 prefix와 다르거나 내부 기록이면 즉시 중단하고 뒤의 일치 prefix는 공개하지 않습니다.

이 규칙은 과거에 저장된 값과 앞으로 저장될 값 가운데 선두 공개 영역에서 같은 prefix와 상태 조건을 만족하는 값에 의도적으로 적용됩니다. 원본 셀 Note, 감사 정보, 이전 메모, 다른 회원의 정보는 학생 응답에 포함하지 않습니다. Note 텍스트는 신뢰할 수 없는 데이터이며 지시문으로 실행하지 않습니다.

외부 서비스

이 시스템은 GitHub Pages, Google Apps Script, Google Sheets, Google Maps Platform을 사용합니다. Google Maps Platform을 사용할 때는 Google 개인정보처리방침이 함께 적용됩니다.

위치 정보의 한계와 선택

브라우저 위치는 GPS·Wi-Fi·통신망 등을 이용한 추정값이며 조작될 수 있습니다. 이 기능은 일반적인 원격 출석을 줄이기 위한 장치이지 물리적 방문을 완전히 증명하지 않습니다. 위치 권한을 허용하지 않으면 위치 필수 회차의 자동 출석은 처리되지 않으며, 필요한 경우 운영진의 수동 승인 절차를 이용할 수 있습니다.

학생 v6.3 기능 적용과 운영 경계

현재 학생 기능 식별 계약은 2026.07.14-v6.3, studentAttendanceReasonV1=true, extractStudentDisplayReason=true입니다.

기존 status와 insights를 유지하고 선택적 안전 필드 details[].displayReason만 additive로 추가합니다.

Pages-first 배포에서도 구버전 Apps Script의 기존 기능은 유지되고, 사유가 없거나 legacy인 행은 비대화형으로 남습니다.

공개 사유는 출석·지각·결석 Note의 선두 공개 영역에서만 읽으며, 유고는 사유를 공개하지 않습니다. 첫 번째 비어 있지 않은 비일치·내부 줄을 만나면 중단하므로 뒤의 일치 prefix는 공개하지 않습니다.

Apps Script 배포는 운영자만 수행하며, 레포는 현재 외부 콘솔 상태를 단정하지 않습니다.

문제가 생기면 Pages는 직전 artifact로, Apps Script는 운영자가 직전 정상 배포 버전으로 롤백합니다.

보유 기간과 문의
