# Video Appendix - Rehearsal Checklist And Recovery Plan

> 문서 링크: [docs/Video/08_Video_Appendix_Checklist_And_Recovery.md](./08_Video_Appendix_Checklist_And_Recovery.md) | [GitHub](https://github.com/cloud-club/CloudClubAttendanceSystem/blob/gh-pages/docs/Video/08_Video_Appendix_Checklist_And_Recovery.md)

## 목적
본 부록은 사용자/운영자 영상을 재촬영 최소 비용으로 완성하기 위한 실행 체크리스트와 복구 플랜입니다.

## A. 리허설 체크리스트

### A-1. 공통(촬영 전 10분)
1. 브라우저 줌 100%, 해상도 고정(권장 1920x1080) 여부 확인
2. 네트워크 상태 점검(페이지 로딩 지연 시 대기 컷 확보)
3. 계정 상태 확인
- 사용자 영상: 학생 페이지 접근 가능
- 운영자 영상: `super` 계정 로그인 가능
4. 촬영 순서대로 탭/문서를 미리 열어 탭 이동 시간을 줄임
5. 음성 테스트(마이크 입력 레벨, 배경 소음) 수행

### A-2. 사용자 영상 리허설
1. `web/` 랜딩에서 `출석하기` 버튼이 즉시 보이는지 확인
2. 학생 페이지에서 전화번호 입력 및 출석 성공 케이스 확보
3. `출석현황` 조회와 랭킹 보드 로딩 확인
4. 모바일 QR 스캔 후 `web/student/latest/` 진입 확인
5. 2분 타임라인 맞춤 여부(씬별 목표 시간 ±5초 이내) 확인

### A-3. 운영자 영상 리허설
1. 9개 탭 모두 노출 확인
2. 수동 승인 데모용 회차/회원 데이터 사전 확보
3. 일정 관리에서 추가/수정/삭제 시연용 날짜 확보
4. super 전용 탭(변수명 관리/시즌 생성·업로드/관리자 관리) 접근 확인
5. `Google Sheets 바로가기` 동작 확인
6. 마감 루틴(출석현황 재확인 + 수료 재확인 + 런북 화면)까지 동선 검증

## B. 촬영 실패 복구 플랜

### B-1. 인증/권한 실패
- 증상: 관리자 탭 접근 불가, 로그인 반복 실패
- 즉시 조치:
1. 브라우저 새로고침 후 재로그인
2. 계정 권한(`season_admin/super`) 확인
3. `_admins`의 `is_active` 상태 확인
- 대체 촬영:
1. 권한 컷은 기존 정상 화면 캡처를 B-roll로 대체
2. 해당 씬 내레이션은 유지하고 조작 컷만 later take로 교체

### B-2. API/로딩 실패
- 증상: 버튼 클릭 후 결과 미표시, 대시보드 로딩 지연
- 즉시 조치:
1. 하드 리로드
2. 시즌 선택 재확인
3. 5초 대기 후 재시도
- 대체 촬영:
1. 성공 컷이 있는 이전 take를 삽입
2. 실패 화면은 편집에서 제거하고 다음 씬으로 점프 컷

### B-3. 데이터 오염/실수 입력
- 증상: 잘못된 회차 저장, 변수 오입력, 의도치 않은 수동승인
- 즉시 조치:
1. 일정: 즉시 수정 또는 삭제
2. 변수: 원래 값으로 복원 후 재저장
3. 수동승인/유고: 운영 기준에 따라 원복 처리 후 재확인
- 대체 촬영:
1. 실수 구간은 잘라내고 복원 완료 상태에서 이어 촬영
2. 내레이션은 "운영 주의점" 중심으로 재녹음

### B-4. 시간 초과
- 증상: 사용자 영상 2분 초과, 운영자 영상 10분 초과
- 즉시 조치:
1. 각 씬 도입 문장 1개만 남기고 중복 문장 제거
2. 스크롤 장면은 1개만 유지
3. 로딩 대기 구간은 타임랩스 또는 컷 삭제
- 대체 편집:
1. 사용자 영상은 Scene 5를 10~12초로 압축
2. 운영자 영상은 Scene 14(마감 루틴) 설명을 40초로 축약

## C. 최종 검수 체크
1. 사용자 영상 2분 이내, 운영자 영상 10분 이내인지 확인
2. 운영자 영상에서 9개 탭이 모두 등장하는지 확인
3. super 전용 탭의 권한 안내 멘트가 포함됐는지 확인
4. 시트 저장 위치 설명(`season_nn`, `_admins`, `variable`, `_session_meta`, `_import_meta`)이 포함됐는지 확인
5. 탭명/버튼명이 UI 표기와 일치하는지 확인
6. 마지막 장면이 "운영 기록 남기기" 메시지로 종료되는지 확인
