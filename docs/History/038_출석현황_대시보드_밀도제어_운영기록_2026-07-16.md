# 출석현황 대시보드 밀도 제어 운영 기록

## 배경과 결정

출석현황은 필터·KPI·차트·드릴다운이 한 카드에 이어져 다른 보조 조회를 사용할 때도 많은 세로 공간을 차지했습니다. 또한 행사명을 모든 차트 축에 항상 붙이면 긴 회차 키와 겹쳐 가독성이 떨어집니다.

대시보드 전체를 기본 열린 `details` 표면으로 바꾸고 제목 행의 꺾쇠로 접을 수 있게 했습니다. 행사명 축 표시는 필터 도구 안의 선택 체크박스로 제공하고 기본값은 끔으로 두었습니다. 체크 시 세 개 회차 기반 차트만 즉시 다시 그리며 데이터 재요청은 하지 않습니다.

## 전화번호 조회 배치

기존에는 조회 결과가 보조 카드 행 아래 독립 영역에 나타났습니다. 결과 컨테이너를 전화번호 입력 카드 내부로 이동하고 중첩 카드 대신 구분선이 있는 컴팩트 결과 표면을 사용합니다.

## 데이터 계약

대시보드 `meta.availableSessions`에 선택적 `eventName`을 추가했습니다. 구버전 Apps Script에서는 필드가 없으므로 토글을 켜도 회차 키만 표시되어 기존 Pages 동작을 유지합니다.

## 검증

JavaScript 구문 검사, 관리자 정적 레이아웃 회귀, 공백 오류 검사를 수행합니다. 실제 차트 라벨 겹침은 최종 Visual QA에서 375px·768px·1280px 화면으로 확인합니다.
