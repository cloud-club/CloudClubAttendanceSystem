# 유고 처리 매트릭스 메모 미리보기 운영 기록

## 배경과 결정

운영자는 매트릭스의 상태만 보고는 기존 처리 근거를 알 수 없어 셀을 클릭해 모달을 반복해서 열어야 했습니다. 관리자 전용 수료 보고서가 이미 회원별 원본 Note를 제공하므로 새 API를 만들지 않고 같은 응답을 호버 미리보기에 재사용합니다.

## UI 계약

- 회차 헤더는 날짜/회차 키 아래 선택 행사명을 작은 보조 텍스트로 표시합니다.
- 상태 셀에 마우스를 올리면 행사명, 상태, 시트 Note를 고정되지 않은 카드로 표시합니다.
- 카드에는 포인터 이벤트를 주지 않아 기존 셀 클릭과 키보드 동작을 방해하지 않습니다.
- 메모가 없으면 `기록된 메모가 없습니다.`라고 명시합니다.

## 데이터와 권한

원본 Note는 기존 `graduationReport` 관리자 응답 안에서만 사용합니다. 학생 공개 응답에는 포함되지 않습니다. 행사명은 수료 보고서의 `sessions[]`에 선택 필드로 추가했습니다.

## 검증과 배포

관리자 JavaScript 구문, 정적 레이아웃, Apps Script 회귀 및 전체 doublecheck를 수행합니다. `33_graduation_manual_excused.gs`를 수동 배포해야 행사명이 응답에 포함되며 Pages는 먼저 배포할 수 있습니다.
