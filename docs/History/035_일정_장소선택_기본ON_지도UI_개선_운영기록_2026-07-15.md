# 일정 장소 선택 기본 ON·지도 UI 개선 운영 기록 (2026-07-15)

## 배경

GPS 기반 출석 판정은 운영 검증을 마쳤지만, 운영진이 회차를 만들 때 장소를 자동완성 검색 결과로만 선택할 수 있었다. 실제 행사장 주변의 지형과 건물 위치를 보면서 세부 장소를 확인하기 어렵고, 위치 제한을 켜는 단계도 빠뜨릴 수 있었다.

이번 개선의 목적은 출석 판정이나 Sheets 저장 형식을 바꾸는 것이 아니라, 일정 추가 시 장소 정책을 더 안전하고 빠르게 설정하는 것이다.

## 결정

- 신규 회차는 `장소 기반 출석 확인 필수`를 기본 ON으로 연다.
- 운영진이 체크를 해제하면 선택된 장소를 제거하고 위치 제한 없는 `gps=0` 회차로 저장한다.
- 기존 회차 수정은 이미 저장된 `locationRequired` 값을 그대로 복원한다.
- 자동완성 검색 아래에 높이 144px의 Google 지도를 배치한다.
- 검색 결과와 지도 장소 핀 선택은 같은 Google Place ID, 표시명, 주소, 위치 미리보기 상태를 갱신한다.
- 지도에서 선택한 장소는 기존과 동일하게 Place ID만 저장하고, Apps Script가 저장 시 좌표를 다시 검증한다.

## 경계와 대안 검토

지도에서 임의 좌표를 클릭해 위도·경도를 Sheets에 저장하는 방식은 채택하지 않았다. 참가자와 장소 좌표를 별도 데이터로 관리하지 않으려는 서버리스 설계와 기존 Place ID 검증 계약을 깨기 때문이다.

임의 좌표를 Place ID로 바꾸기 위한 Geocoding API 추가도 채택하지 않았다. 별도 API 활성화·과금·키 제한 운영이 늘어나며, 역지오코딩 결과가 사용자가 누른 정확한 지점을 항상 대표하지 않기 때문이다. 대신 지도에서는 Google이 Place ID를 제공하는 장소 이름 핀을 선택하고, 핀이 없는 주소는 기존 검색 입력으로 선택한다.

## 배포 영향

- 변경 계층: `web/*`, 디자인 정본, 운영 Wiki, 정적 회귀 검사
- Apps Script 및 Sheets 데이터 계약: 변경 없음
- 수동 콘솔 작업: 없음
- 배포: GitHub Pages만 필요
- 비용 경계: 지도 표시는 Dynamic Maps 로드로 집계되며 현재 공식 가격표의 월 10,000회 무료 사용량을 넘으면 과금될 수 있다.
