# 통합 시각 검증과 접근성 보정 운영 기록

## 배경

행사 일정, 수료 조항, 공용 출석 이력처럼 여러 탭에서 재사용되는 UI를 모바일·태블릿·데스크톱으로 함께 검증했습니다. 정적 테스트만으로는 찾기 어려운 일정 카드 내부 스크롤, 직접 진입 시 정책 데이터 미로딩, 긴 시즌 모달의 세로 범위를 실제 렌더링에서 확인했습니다.

## 보정한 계약

- 학생 행사 일정은 내부 400px 스크롤을 사용하지 않고 페이지 흐름 안에서 모든 회차를 표시합니다.
- 768px 이하에서는 행사 정보, 위치 안내, 지도 버튼을 세로로 배치해 한국어 문구가 좁은 칸에서 음절 단위로 끊기지 않게 합니다.
- 행사 일정 탭과 수료 조건 탭은 같은 `studentSchedule` 요청을 공유하며, 중복 요청은 하나의 Promise로 합칩니다.
- 수료 조건 팝업은 직접 진입해도 현재 시즌 정책을 먼저 불러오고, Escape·배경 클릭·Tab 순환·초점 복원·본문 스크롤 잠금을 제공합니다.
- 관리자 공용 출석 이력 모달은 화면 높이 안에서 헤더·요약·스크롤 본문·닫기 동작을 유지합니다. Escape·배경 클릭·Tab 순환과 호출 버튼 초점 복원을 지원합니다.
- 일정에서 위치 확인을 끄면 장소 검색·지도·반경 정책 영역의 `hidden` 상태가 기존 grid 스타일보다 항상 우선합니다.
- 데스크톱 일정 모달에서 위치 확인을 끄면 장소 토글이 불필요하게 전체 높이를 차지하지 않고, 회차 메모 영역이 가로 폭을 활용합니다.
- 모바일 관리자 캘린더는 7열을 좁은 화면에 강제로 압축하지 않고 캘린더 내부 가로 스크롤을 사용해 날짜, 추가 버튼, 행사명이 겹치지 않게 합니다.
- 관리자 유고 입력 팝업과 현재 운영 문서는 유고 사유를 관리자 전용 메모로 설명하며, 학생에게는 `유고` 상태만 공개한다는 API·UI 경계를 동일하게 유지합니다.
- 모바일 유고 입력 안내에서는 `학생에게는 유고 상태만 표시합니다.` 문장을 하나의 의미 단위로 유지합니다.
- 학생 행사 일정의 장소 안내는 출석 상태용 `예정` 회색을 상속하지 않고 본문 대비 색상을 별도로 사용합니다.
- 사용자 화면에 내부 구현 표식인 `TODO(member_role)`를 노출하지 않습니다.

## 검증 범위

13개 화면 상태를 375×812, 768×1024, 1280×900에서 각각 캡처해 총 39장을 확인합니다. 유고 입력 팝업도 별도 시나리오로 포함해 관리자 전용 메모 안내와 학생 비공개 경계를 세 화면 크기에서 검증합니다. 캡처는 마지막 소스 수정 뒤 새로 생성하고 PNG 서명, 요청 해상도, 전역 가로 오버플로, 한국어 줄바꿈, 모달 스크롤을 함께 검사합니다.

## 배포 메모

이 보정은 Pages 정적 파일에만 해당합니다. Apps Script 수동 배포 파일 목록에는 새 파일이 추가되지 않습니다. 학생 JavaScript 캐시 키는 `20260716-ui8`로 갱신했습니다.
