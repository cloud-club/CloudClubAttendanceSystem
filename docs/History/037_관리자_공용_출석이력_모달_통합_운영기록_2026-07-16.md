# 관리자 공용 출석 이력 모달 통합 운영 기록

## 문제

회원 출석 이력을 확인하는 기능이 출석현황 대시보드 내부 필터에 종속되어 있었고, 출석하기·유고 처리·수료 판정에서는 같은 정보를 바로 열 수 없었습니다. 화면마다 별도 팝업을 만들면 개인정보 표시와 Note 해석 규칙이 서로 달라질 위험이 있었습니다.

## 결정

기존 관리자 전용 `attendanceDashboardDrilldown`의 회원 조회를 공용 모달의 단일 데이터 원천으로 재사용합니다. 모든 진입점은 전화번호 기반 회원 키를 전달하며, 모달은 현재 대시보드 필터를 적용하지 않고 선택 시즌 전체 회차를 요청합니다.

## 연결 범위

- 출석하기: 회원 행의 개별 멘트 버튼 왼쪽
- 출석현황: 그래프 드릴다운 회원 목록과 상태 순위, 하단 출석 순위 이름 셀
- 유고 처리: 회원/연락처 고정 셀
- 수료 판정: 회원 셀

## 표시 계약

관리자는 회차 키, 행사명, 날짜, 출석·지각·결석·유고·미확정 상태, 출석 시각, 시트 Note를 볼 수 있습니다. 관리자 전용 경로이므로 유고 메모도 운영 목적으로 표시되며, 학생 공개 상세 계약과 분리합니다.

## 검증과 배포

변경 JavaScript 구문과 정적 회귀 게이트를 확인합니다. Apps Script의 드릴다운 행에 행사명을 추가했으므로 해당 파일을 수동 배포해야 완전한 표시가 활성화됩니다. Pages는 이와 독립적으로 먼저 배포할 수 있습니다.
