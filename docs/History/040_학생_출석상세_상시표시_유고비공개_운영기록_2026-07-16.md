# 학생 출석 상세 상시 표시와 유고 비공개 운영 기록

## 결정

학생 현황 결과의 회차별 목록을 접힌 `details`에서 일반 `section`으로 바꿔 조회 즉시 보이게 했습니다. 출석·지각·결석에 서버가 공개한 사유가 있을 때만 기존 상세 다이얼로그를 열 수 있습니다.

유고는 민감한 개인 사정이 포함될 가능성이 높으므로 학생 공개 API에서 `displayReason`을 생성하지 않습니다. 프런트엔드 sanitizer도 유고 사유를 허용하지 않아 구버전·캐시·변조 응답이 오더라도 상태 `유고`만 남깁니다.

## 관리자와의 경계

관리자 공용 출석 이력과 유고 처리 화면은 운영 권한 안에서 원본 Note를 계속 확인할 수 있습니다. 이번 제한은 전화번호 기반 학생 공개 `status` 응답과 학생 UI에만 적용합니다.

## 검증

- API 상태 상세에서 유고 `displayReason` 속성 부재
- 희소 회차 열과 Note 범위 읽기 유지
- 클라이언트 sanitizer·캐시에서 유고 사유 제거
- 상시 표시 section과 출석·지각·결석 다이얼로그 회귀
- 정적 개인정보/구조 가드
