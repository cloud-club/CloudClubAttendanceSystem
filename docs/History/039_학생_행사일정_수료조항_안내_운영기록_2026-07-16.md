# 학생 행사 일정과 수료 조항 안내 운영 기록

## 배경

학생은 출석 가능 시간과 개인 현황은 확인할 수 있었지만 시즌 전체 행사와 위치를 한 화면에서 볼 수 없었습니다. 수료 판정 결과는 제공했으나 첫·마지막 행사 필수와 지각 환산 같은 규칙을 조회 전에 이해하기도 어려웠습니다.

## 공개 API 경계

공개 `studentSchedule` 액션을 추가했습니다. 응답은 행사명, 시작·마감 표시, 장소 안내, Google 지도 링크, 필수 위치 표식과 요약 수료 정책만 포함합니다. 회원 정보, 시트 원본 Note, 좌표, 관리자 메모는 포함하지 않습니다.

첫·마지막 필수 표시는 `required_session_positions` 변수를 정본으로 사용합니다. 현재 레포 기본값은 `first,last`이나 실제 운영 Script Properties와 시트 상태는 배포 후 운영자가 확인해야 합니다.

## UI와 하위 호환

학생 탭을 네 개로 확장하고 데스크톱 탭과 모바일 메뉴가 같은 DOM 계약을 사용합니다. 새 Apps Script가 배포되지 않은 Pages-first 상태에서는 일정 영역에 업데이트 안내를 표시하고 출석·현황·수료의 기존 기능은 계속 동작합니다.

수료 조건 카드의 `출석 조항 확인하기`는 일정 응답의 정책 값을 설명하는 모달을 엽니다. 일정 응답 전에는 안전한 일반 설명을 제공하고 첫·마지막 필수 회차를 명시합니다.

## 배포

Pages는 즉시 배포할 수 있습니다. 일정 데이터와 정책 팝업의 실제 시즌 값은 `01_constants_access.gs`, `00_entry_api.gs`, `32_schedule.gs`가 포함된 Apps Script 배포 후 활성화됩니다.
